# PDF 壓縮工具

單一 HTML 檔的 PDF 壓縮器，全部在瀏覽器裡完成，檔案不會上傳到任何伺服器。由 Hermes Agent 產生，2026-06。

## 原理

1. 用 [pdf.js](https://mozilla.github.io/pdf.js/) 3.11 把每一頁以原始尺寸（scale 1.0）畫到 canvas
2. canvas 轉成 JPEG，品質由滑桿決定（0.15～1.0，預設 0.4）
3. 用 [pdf-lib](https://pdf-lib.js.org/) 1.17 建立新 PDF，每頁放一張 JPEG
4. 顯示原始大小、壓縮後大小與縮減比例，提供下載

選好檔案（點選或拖放）會自動開始壓縮，進度條顯示目前頁數。

## 取捨

- **每一頁都會變成圖片**：文字不能再選取或搜尋，向量圖與字型會被點陣化。適合掃描檔或以圖片為主的 PDF；純文字 PDF 壓完可能反而變大，頁面上會顯示「未縮減」。
- 以 scale 1.0 渲染（約 72 DPI），品質調高也不會比這個解析度更清楚。
- 兩個函式庫從 unpkg CDN 載入，需要網路。

## 使用

直接用瀏覽器開 `index.html`。
